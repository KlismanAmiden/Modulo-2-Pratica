# Módulo 02 — Padrões de Projeto — Prática

Este repositório contém as atividades práticas do **Módulo 02 — Padrões de Projeto**, com foco na aplicação de convenções utilizadas no Git e no desenvolvimento de software.

## Organização do repositório

```text
.
├── README.md
└── respostas.md
```

### Arquivos

- `README.md` — apresenta a organização e o objetivo do repositório.
- `respostas.md` — contém os enunciados dos exercícios e suas respectivas respostas.

## Conteúdos abordados

A prática aborda os seguintes conceitos:

1. Mensagens de commit
2. Nomes de branches
3. Versionamento semântico (SemVer)
4. Tags
5. Pull Requests

O objetivo é aplicar esses conceitos em situações práticas de desenvolvimento, seguindo as convenções apresentadas na parte teórica do módulo.
